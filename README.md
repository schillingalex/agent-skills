# agent-skills

My personal collection of skills for things I need. Everything is a work in progress.

**Installation (all skills):**

```bash
npx skills add https://github.com/schillingalex/agent-skills
```

# learning-by-doing

The agent will try to teach a programming language, framework, or concept based
on a user-specified project goal.
The agent makes lessons in collaboration with the user towards the project goal.
The agent checks lesson completion and gives feedback.

**Installation (this skill):**

```bash
npx skills add https://github.com/schillingalex/agent-skills --skill learning-by-doing
```
